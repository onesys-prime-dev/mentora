## How each was confirmed

- **Probe:** a test written only for this check (kept outside the repository, in the QA scratchpad) set up the situation on `mentora_test` and asserted the decided behavior. It failed. TC-QUIZ-07 also had a control run without the edit, which passed, so the failure is the defect and not the probe.
- **Schema:** read-only queries of `mentora_test`'s `information_schema`.
- **Code:** the file and line are cited; the behavior follows directly from them.
- **Not found:** the route, setting or code path the requirement needs does not exist.

One case was **not** a defect after all: TC-ASG-06. Its "another section" fallback applies only to an assignment in no module, and a code comment states it as deliberate; under rule I1.1 it governs (register Part I4). The case was corrected to expect the code's behavior.
