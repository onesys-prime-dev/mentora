# Sample templates

These are working examples generated by Mentora itself, from real demo course data (IT101, "Introduction to Computing," section A). We're not waiting on a supervisor-supplied format — these are our proposal for review. If you'd like changes to the layout, wording, or columns, let us know and we'll adjust the generator.

## Question bank (`question-bank-sample.docx` / `.rtf`)

Exported from "Quiz 1: Variables and Data Types." An instructor downloads this to edit a quiz's questions offline (in Word or any RTF-capable editor), then re-uploads it — the changes are previewed before anything is saved.

- Each question is followed by its choices (for multiple choice) and one small metadata line marked `[machine-readable — do not edit]`, which records the question's ID, type, points and correct answer(s). This line is what makes re-importing exact — everything above it can be freely rewritten.
- A Short Answer question shows its accepted answers on their own line, so the instructor can see and edit the answer key directly.

## Grade sheet (`grade-sheet-sample.xlsx` / `.csv`)

Exported from IT101-A's gradebook. An instructor downloads this to enter scores for non-quiz work (Attendance, Participation, etc.) offline, then re-uploads it.

- **Only the light-yellow columns are editable** — manual items like Class Participation. Quiz and assignment scores are locked; they always come from grading inside Mentora, never from this file.
- **In Excel**, the category percentages, final percentage, letter grade and remarks are live formulas — they recompute as scores are typed in, using this section's actual grading scheme (currently Quizzes 40% / Assignments 40% / Participation 20%, in this sample).
- **The CSV** has the same columns, but as plain numbers (a CSV can't hold formulas) — it's meant for simple bulk edits rather than working the sheet live in Excel.
- Re-importing a file checks it against the grading setup it was exported under. If the setup changed since (categories, weights, or points), or a locked cell was edited, the file is refused or that row is flagged — it's never silently accepted.

## Open questions for the supervisor

1. Does this question format work for how quizzes are written today, or is there an existing house style to match?
2. Does the grade sheet need extra columns — e.g. a remarks/comments column per student, or a separate column for grading period (prelim/midterm/finals)?
3. Is there an official grading scale or transmutation table we should use as the default, in place of the placeholder scale currently shipped (1.00–5.00, 75% passing)?
