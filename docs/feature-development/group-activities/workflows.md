# Workflows (draft for approval)

## Instructor / Chairperson
1. **Create a set** (Groups tab): name, mode (manual, auto, self-signup, proposed), size min-max, window. Groups are built per mode (auto shows a preview first).
2. **Attach to an activity** (activity editor "Groups"): pick a set and its groups are copied. Set ungrouped policy, submission style, leader-only toggles, grading mode and rubric scopes, deadline.
3. **Run the activity:** monitor groups (flags for below-min and ungrouped), approve proposals, add late enrollees, extend a group's deadline, unlock a frozen group (confirmation and reason).
4. **Grade** (Grade Work): group view, then a collective score or rubric, per-student adjustment and private note, or per-student grading. Fan-out saves atomically.
5. **After grading:** removal and addition prompts (keep or excuse; grade separately or inherit).

## Student
1. Gets notified of grouping or the signup window. The activity page shows a "Your group" card.
2. Self-signup: join an open group (race-safe), or propose a group and invite others. In manual or auto modes the instructor places them.
3. Leader-only activities: nominate and vote on a leader, rename the group (per rules). Leave or switch only until the first submission.
4. Submit (shared, leader-only or per-member). See the group grade, own adjustment and reason, and feedback.
5. Ungrouped: blocked ("not in a group yet") or may work alone.
6. Learning item: see the roster and complete it per the setting.

## Dean / Parent / Admin
- Dean: read-only views. Parent: child's group and group grade. Admin: no group tooling.

## System
- Dropped student: auto-removed from groups (D9), with the D10 prompt if already graded.
- Leader drops: next-joined member becomes leader.
- Window closes: flag below-min groups and notify ungrouped students.
- Finalized offering: all group writes refused.
